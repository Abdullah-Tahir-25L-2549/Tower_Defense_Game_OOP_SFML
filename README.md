# Tower_Defense_Game_OOP_SFML
Modern Tower Defense game built with C++ and SFML. Includes 5 tower types, 5 enemy classes, wave management, upgrade/sell mechanics, textures, sounds, and clean Object-Oriented architecture.

A complete Tower Defense game developed in **C++** using **SFML** and **Object-Oriented Programming (OOP)** concepts.


# Features

- 5 Unique Towers
  - Cannon Tower
  - Sniper Tower
  - Machine Gun Tower
  - Slow Tower
  - Laser Tower

- 5 Enemy Types
  - Basic Enemy
  - Fast Enemy
  - Tank Enemy
  - Flying Enemy
  - Splitter Enemy

- Wave System
- Upgrade & Sell System
- Sound Effects
- Health & Gold System
- Victory and Game Over Screens
- Animated Path Rendering
- SFML Graphics & Audio

---

# Technologies Used

- C++
- SFML 3.0
- Object-Oriented Programming

---

# Controls

| Key / Mouse | Action |
|---|---|
| 1 - 5 | Select Tower |
| Left Click | Place / Select Tower |
| ESC | Deselect Tower |
| ENTER | Start Game |
| R | Restart Game |

---

# How to Run

## Requirements

- SFML 3.0
- C++ Compiler
- Visual Studio / g++

---

## Build Command (g++)

```bash
g++ *.cpp -o game -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio
```

---

# Project Structure

```text
assets/         -> textures and sounds
Game.cpp        -> main game logic
Enemy.cpp       -> enemy classes
Tower.cpp       -> tower classes
WaveManager.cpp -> wave handling
```
